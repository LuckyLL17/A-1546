## 测试概述

### 测试目标

本次测试针对校园二手物品交易与资源共享平台后端系统进行全面的API测试和集成测试，主要验证：

- ✅ 各模块API接口的功能正确性
- ✅ 输入验证与参数校验逻辑
- ✅ JWT认证与权限控制机制
- ✅ 模块间协作与数据流转
- ✅ 业务流程完整性（交易、聊天、通知等）
- ✅ 数据库表关系与约束设计
- ✅ 统一响应格式与错误码体系

### 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        Express 应用层                            │
├─────────────────────────────────────────────────────────────────┤
│  中间件层: CORS | JSON解析 | 请求日志 | 认证中间件 | 错误处理    │
├─────────────────────────────────────────────────────────────────┤
│  路由层: 用户路由 | 物品路由 | 订单路由 | 资源路由 | 聊天路由...  │
├─────────────────────────────────────────────────────────────────┤
│  控制器层: userController | itemController | orderController... │
├─────────────────────────────────────────────────────────────────┤
│  服务层: userService | itemService | orderService | chatService  │
├─────────────────────────────────────────────────────────────────┤
│  数据层: MySQL连接池 | 查询封装 | 事务支持                       │
└─────────────────────────────────────────────────────────────────┘
```

1. **架构分层清晰**

   - 中间件统一处理认证、错误、日志
   - 工具类模块化(validator/response/logger/database)

2. **类型安全**
   - 全面使用TypeScript类型定义
   - 接口定义完整(JWTPayload/ApiResponse/PaginatedData)

3. **安全设计**
   - JWT认证中间件支持必需/可选两种模式
   - 密码使用bcrypt加盐哈希存储
   - CORS配置完善
   - 请求体大小限制(10mb)

4. **统一规范**
   - 统一响应格式 {code, message, data, timestamp}

   - 统一分页响应结构
   - 优雅关闭机制(SIGTERM/SIGINT处理)

5. **数据库设计**
   - 外键约束保证数据一致性

   - utf8mb4字符集支持完整Unicode
   - 连接池提升性能

6. **可观测性**
   - 请求日志记录(方法/URL/状态码/耗时/IP/用户ID)
   - 分级日志(debug/info/warn/error)
