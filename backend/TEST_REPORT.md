# 校园二手物品交易平台 - API 测试报告

## 1. 测试概述

### 1.1 测试目的

本次测试旨在对校园二手物品交易与资源共享平台后端系统进行全面的 API 测试和集成测试，验证各模块功能的正确性以及模块间的协作能力。

### 1.2 测试范围

- **用户模块**：注册、登录、个人信息管理、密码修改、用户公开信息查询
- **物品模块**：物品创建、发布、详情查询、搜索、收藏、更新、删除、分类管理
- **订单模块**：订单创建、支付、发货、确认收货、取消、评价、订单列表查询
- **资源共享模块**：资源创建、发布、搜索、下载、点赞
- **聊天模块**：消息发送、会话管理、未读消息、已读标记
- **通知模块**：通知列表、未读计数、标记已读、删除通知
- **举报模块**：举报创建、举报列表查询

### 1.3 测试环境

| 项目 | 说明 |
|------|------|
| 操作系统 | macOS / Linux |
| 运行时环境 | Node.js 18+ |
| 测试框架 | Jest 29.7.0 |
| HTTP 测试库 | Supertest |
| 数据库 | MySQL 8.0 |
| 编程语言 | TypeScript 5.x |
| 服务框架 | Express 4.x |

### 1.4 测试类型

- **API 单元测试**：针对单个接口的功能测试
- **集成测试**：跨模块的完整业务流程测试
- **权限测试**：验证接口的访问控制
- **边界测试**：验证参数边界条件和异常情况处理

  // Arrange - 准备测试数据
